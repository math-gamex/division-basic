An interactive, multilingual game that teaches **long division step-by-step**:  
**Story → Break apart → Divide → Combine → Explain**

**Live Demo:** https://math-gamex.github.io/division-basic/

---

## ✨ Features
- **Stepwise learning flow**: Story → Split (tens/ones) → Division → Combine → Explain  
- **Multilingual**: English 🇬🇧 / Korean 🇰🇷  
- **Themes & sizes**: Dark/Light, Normal/Big UI  
- **Touch-friendly**: drag-and-drop and tap-to-move  
- **Celebration UX**: sound & confetti on success  
- **Zero dependencies**: Pure HTML/CSS/JS (no build needed)
