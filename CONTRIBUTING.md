# Contributing Guidelines

Thank you for your interest in improving this project! Small fixes, feature additions, and bug reports are all welcome.

## Workflow
1. Open an issue to discuss your idea or bug.
2. Fork the repository and create a feature branch.
3. Implement your changes and commit.
4. Submit a pull request with a clear description and screenshots if applicable.

## Code Style
- Use consistent indentation (2 spaces).
- Use meaningful names for variables and functions.
- Keep pull requests small and focused.

## Manual Testing
- Check both desktop and mobile browsers.
- Ensure keyboard navigation works across all steps.
- Verify EN/KR language toggle.
